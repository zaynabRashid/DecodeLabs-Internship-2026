# Expense Tracker

## Project 2 – Python Programming

This project is developed as part of the **DecodeLabs Industrial Training Program 2026**.

The Expense Tracker is a Python-based application that allows users to record, view, delete, and calculate their expenses. The project focuses on **data accumulation, numerical processing, file handling, and programmatic logic**.

##  Objective

The main objective of this project is to create a program where users can enter expense amounts and the program continuously accumulates those amounts to calculate and display the **Total Expense**.

# Features

### Add Expense
- Enter an expense name and amount in PKR.
- Save the expense to the CSV file.

### View Expenses
- Display all recorded expenses.
- Show the expense name and amount clearly.

### Delete Expense
- Search for an expense by name.
- Remove the selected expense from the records.

### Calculate Total Expense
- Calculate the total amount spent using accumulator logic.
- Display the total expense in PKR.

### Data Storage
- Store expense records in a CSV file.
- Keep expense data available for future use.

### Input Validation
- Prevent empty expense names.
- Reject invalid or non-numeric amounts.
- Prevent zero or negative expense amounts.

### Error Handling
- Handle missing expense files.
- Handle invalid data without crashing the program.

### Menu-Driven Interface
- Simple numbered menu for easy navigation.
- Options for adding, viewing, deleting, and calculating expenses.

## How to Run
Python 3.13 must be installed on the system.
Open the project directory in Visual Studio Code and run:
python Expense.py
